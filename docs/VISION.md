# SwarmLink — Vision & Design Philosophy

> *"One sky, many eyes."*

## 我们想解决什么

无人机图传，表面看是个"把画面传过去"的问题。但当你把场景从"一个人戴眼镜飞"扩展到"一群人同时看同一架飞机"——景区游客、消防指挥、飞行培训——问题就变了：

**不是"怎么传"，是"怎么一对多地、稳地、省地传"。**

今天的主流方案各有各的盲点：

- **裸广播（WFB-ng 等）** 快且轻，但没有会话概念。N 个人同时看，丢包了各自喊重传，带宽被 N 倍放大，画面集体花。
- **闭源商业方案** 能做到万台级并发，但黑盒。你买得到服务，买不到理解。出问题时你只能等厂商回复邮件。
- **通用视频协议（RTMP / WebRTC）** 为点对点优化，一对多要靠中心服务器硬转发，延迟和带宽成本都不适合空地链路。

**SwarmLink 想做第四种选择：开源、可审计、一对多原生、弱网下能自愈。**

## 设计哲学

### 1. 站在成熟方案的肩膀上

不重复造轮子——从经过大规模验证的系统里，选择对图传场景适用且经过论证的设计，只实现需要的部分，并明确记录取舍。

| 参考来源 | 借鉴的设计 | 明确舍去 |
|---|---|---|
| **QUIC** | 多路复用、可插拔拥塞控制思想 | 证书链、HTTP/3 帧 |
| **WebRTC SFU** | 选择性转发、分层码率思路 | ICE/SDP 复杂性 |
| **CDN** | 路由与缓存思路 | 全量 DNS / GeoIP |
| **Starlink RLC** | 传输模式自适应 | 卫星轨道预测 |
| **MTProto** | 会话隔离、ARQ 聚合 | IGE 加密、云同步 |

> 我们的价值不在"发明传输技术"，而在**为无人机弱网图传场景做正确的取舍与工程化**：哪些成熟设计该用、哪些该舍、怎么组合成一个完整可用的系统。

### 2. FEC 优先，ARQ 兜底

重传要等一个往返，图传等不起。所以默认靠 **FEC（前向纠错）** 当场修——丢了 4 片以内，数学上直接算回来，零延迟。

只有 FEC 修不了的（极端丢包），才升 ARQ 重传。而且 N 个人要同一片 → 合并成 1 次重传 → 带宽只花 1/N。

**这是 SwarmLink 在弱网下"抖一下就自愈"的设计核心。**

### 3. 协议是骨架，系统是肉身

很多项目止步于"协议库"。SwarmLink 的野心是**完整系统**——真实视频可跑、Docker 一键部署、Web 界面看状态。

协议库是给开发者看的，系统是给用户用的。我们要后者。

### 4. 开源不是营销话术，是设计约束

MIT 许可，最宽松的约束：任何人在任何场景都能自由使用、修改、商用。我们相信**项目靠能力和生态赢得使用，而不是靠许可限制**。

**我们不怕被抄，我们怕没人用。**

## 非目标（Non-Goals）

明确不做什么，和做什么一样重要：

- ❌ **不做硬件**：不造天线、不焊板子、不碰射频前端。我们做协议和软件，硬件交给 WFB-ng 生态和硬件厂商。
- ❌ **不做视频编码**：不写 H.264/H.265 编码器，用系统已有的硬编/软编，我们只管"编码后的比特流怎么传"。
- ❌ **不做实时操作系统**：不碰 RTOS、不优化到微秒级。我们的目标是"够用且优雅"，不是"极限压榨"。
- ❌ **不做闭源版本**：没有"社区版"和"企业版"的分裂。一个版本，MIT，所有人看到一样的代码。

## 成功长什么样

三年后，如果 SwarmLink 成功了，应该是这样的：

1. **GitHub 上 5k+ Stars**，Contributors 来自 10+ 个国家
2. **至少 3 个景区**在用 SwarmLink 做"一飞多看"的游客体验
3. **至少 1 篇学术论文**引用 SwarmLink 作为实验平台
4. **消防/电力巡检**至少有一个行业用户，因为"开源可审计"选了我们
5. **WFB-ng 用户迁移过来**不需要重新学一套东西，因为 SwarmLink 兼容它的硬件

## 给贡献者的话

如果你读到这里，说明你对这个项目有点兴趣。几件事想让你知道：

- **代码风格**：Python 优先（可读性 > 性能），热点用 C/Rust 重写。命名清晰比聪明更重要。
- **测试不是可选项**：每个 PR 必须有测试。我们不追求 100% 覆盖，但核心路径（Header 解析、FEC 编解码、ARQ 聚合）必须有。
- **文档和代码同等重要**：一个没有 README 的模块等于不存在。
- **争吵欢迎，人身攻击不欢迎**：技术分歧我们掰开了揉碎了说，但对事不对人。
